1

Schleifen

Doppelstunde 1Aufgabenblätter A2 & A3

ZielDu erkennst Wiederholungen in einer Figur und drückst sie mit einer Schleife aus, statt Befehle abzutippen.

Ein Quadrat besteht aus vier gleichen Schritten: hundert vorwärts, neunzig Grad nach rechts. Statt diese zwei Zeilen viermal zu schreiben, sagst du der Turtle einmal, dass sie sie wiederholen soll. Entscheidend ist die Einrückung: Alles, was um vier Leerzeichen eingerückt unter repeat steht, gehört zur Schleife.

from gturtle import *

makeTurtle()

repeat 4:
    forward(100)
    right(90)

Zwei Schreibweisen

repeat n: ist eine Besonderheit von TigerPython. In jedem anderen Python schreibt man for i in range(n): – das versteht TigerPython ebenfalls. Beide Programme zeichnen dasselbe. Gewöhne dich an die for-Variante, denn du brauchst gleich die Zählvariable i.

repeat 6:
wiederhole den eingerückten Block sechsmal
for i in range(6):
dasselbe, aber i zählt dabei 0, 1, 2, 3, 4, 5 mit
360 / n
der Drehwinkel für ein regelmäßiges n-Eck

Für ein regelmäßiges Vieleck gilt: Die Turtle muss sich insgesamt einmal komplett drehen, also 360°. Bei sechs Ecken sind das 60° pro Ecke.

from gturtle import *

makeTurtle()

# 6 Ecken -> 360 / 6 = 60 Grad pro Ecke
for i in range(6):
    forward(100)
    left(60)

Eine Schleife darf auch mehr als zwei Zeilen enthalten. Eine Treppenstufe besteht aus einem Schritt nach oben und einem nach rechts – siebenmal wiederholt ergibt das eine Treppe:

from gturtle import *

makeTurtle()

repeat 7:
    forward(20)
    right(90)
    forward(20)
    left(90)

Und eine Schleife darf in einer anderen Schleife stecken. Die innere zeichnet eine Figur, die äußere dreht sie weiter – so entstehen die Rosetten:

from gturtle import *

makeTurtle()
hideTurtle()

repeat 12:            # 12 mal ein Quadrat ...
    repeat 4:         # ... und jedes Quadrat aus 4 Seiten
        forward(80)
        right(90)
    left(30)          # dann die ganze Figur weiterdrehen

Gefüllte Figuren (Blatt A3)

Setze zuerst die Füllfarbe, dann zeichne die Figur zwischen startPath() und fillPath(). Ein Kreis ist dabei einfach ein Vieleck mit sehr vielen, sehr kurzen Seiten.

from gturtle import *

makeTurtle()
hideTurtle()
setFillColor("green")

startPath()
repeat 360:
    forward(1)
    left(1)
fillPath()

Funktionen

Doppelstunde 2Aufgabenblatt A4

ZielDu gibst einer Folge von Befehlen einen Namen und kannst sie danach wie einen eingebauten Turtle-Befehl benutzen.

Mit def erfindest du einen neuen Befehl. Der Block darunter ist der „Bauplan“ – beim Definieren passiert noch nichts. Erst der Aufruf sechseck() lässt die Turtle wirklich zeichnen. Die runden Klammern gehören immer dazu, beim Definieren wie beim Aufrufen.

from gturtle import *

def sechseck():           # Bauplan: neuer Befehl
    repeat 6:
        forward(50)
        left(60)

makeTurtle()
hideTurtle()

sechseck()                # Aufruf: jetzt wird gezeichnet

Warum sich das lohnt

Lesbarkeit
im Hauptprogramm steht, was passiert, nicht wie
Wiederverwendung
ein Befehl, beliebig oft aufrufbar – auch in einer Schleife
Fehlersuche
stimmt die Figur nicht, musst du nur an einer Stelle korrigieren

Der eigentliche Gewinn zeigt sich, wenn du deinen neuen Befehl in eine Schleife steckst. Zwölf Sechsecke, jedes um 30° weitergedreht:

from gturtle import *

def sechseck():
    repeat 6:
        forward(50)
        left(60)

makeTurtle()
hideTurtle()

repeat 12:
    sechseck()
    left(30)

Achte auf die Reihenfolge im Programm: Erst alle def-Blöcke, dann makeTurtle(), dann das Hauptprogramm. Eine Funktion muss definiert sein, bevor sie aufgerufen wird. Für ein Quadrat auf der Spitze drehst du die Turtle vorher um 45°:

from gturtle import *

def raute():
    left(45)
    repeat 4:
        forward(60)
        right(90)
    right(45)             # Turtle wieder in die Ausgangsrichtung

makeTurtle()
hideTurtle()

raute()

Merke: aufräumen nicht vergessen

Eine gute Funktion hinterlässt die Turtle in einem vorhersehbaren Zustand – am besten in Position und Richtung wie zu Beginn. Sonst stimmt beim zweiten Aufruf nichts mehr.

Variablen & Parameter

Doppelstunde 3Aufgabenblatt A5

ZielDu speicherst Werte in Variablen, veränderst sie in jedem Schleifendurchlauf und übergibst sie als Parameter an deine eigenen Funktionen.

Eine Variable ist ein benannter Behälter für einen Wert. s = 5 legt den Wert 5 unter dem Namen s ab. Das Gleichheitszeichen ist dabei keine mathematische Aussage, sondern ein Befehl: „Rechne die rechte Seite aus und speichere sie links.“ Deshalb ergibt s = s + 1 Sinn – es heißt: nimm den alten Wert, erhöhe ihn um eins, speichere ihn wieder.

from gturtle import *

makeTurtle()
hideTurtle()

s = 5                 # Startwert
repeat 100:
    forward(s)
    right(90)
    s = s + 2         # jede Seite 2 laenger als die vorige

Zwei Arten, eine Variable weiterzuzählen

s = s + 2
gleichmäßiges Wachstum – es entsteht eine Spirale
s = s * 0.9
Wachstum um einen Faktor – die Figur schrumpft und dreht sich ein
range(1, 101)
Alternative: for s in range(1, 101): zählt s selbst hoch

Ein Parameter ist eine Variable, die eine Funktion beim Aufruf geschenkt bekommt. So wird aus dem einen festen Quadrat ein Quadrat in jeder gewünschten Größe. Der Name in den Klammern der def-Zeile ist der Parameter, der Wert beim Aufruf ist das Argument:

from gturtle import *

def square(s):            # s ist der Parameter
    repeat 4:
        forward(s)
        right(90)

makeTurtle()
hideTurtle()

square(30)                # kleines Quadrat
square(80)                # grosses Quadrat

Richtig stark wird das in Kombination mit einer Variablen, die sich pro Durchlauf ändert – Funktion, Schleife und Variable greifen ineinander:

from gturtle import *

def square(s):
    repeat 4:
        forward(s)
        right(90)

makeTurtle()
hideTurtle()

s = 100
repeat 40:
    square(s)
    right(9)              # Figur weiterdrehen
    s = s * 0.97          # und ein wenig verkleinern

Mehrere Parameter & Zufallsfarben

Eine Funktion darf mehrere Parameter haben, getrennt durch Komma. Für Aufgabe 5 hilfreich: getRandomX11Color() liefert eine zufällige Farbe, die du direkt an setPenColor() weitergeben kannst.

from gturtle import *

def vieleck(n, s):
    repeat n:
        forward(s)
        left(360.0 / n)   # Punkt-Null, damit sauber geteilt wird

makeTurtle()
hideTurtle()

vieleck(8, 40)            # Achteck mit Seitenlaenge 40
vieleck(3, 90)            # Dreieck mit Seitenlaenge 90

Bedingte Anweisungen

Doppelstunde 4Aufgabenblatt A6

ZielDein Programm trifft Entscheidungen: Es zeichnet je nach Situation unterschiedlich – abhängig von einer Variablen, einer Position oder dem Zufall.

Eine Bedingung ist eine Frage, auf die es nur „ja“ oder „nein“ gibt. Ist die Antwort ja, wird der eingerückte Block hinter if ausgeführt, sonst der hinter else. Achte auf das doppelte Gleichheitszeichen: = speichert, == vergleicht.

Vergleichen und verknüpfen

== !=
gleich · ungleich
< > <= >=
kleiner · größer · kleiner-gleich · größer-gleich
and or not
beide Bedingungen · mindestens eine · Umkehrung
a % b
Rest der Division – 8 % 3 ergibt 2
s % 2 == 0
ist wahr, wenn s gerade ist

Damit lässt sich die Spirale aus Doppelstunde 3 einfärben: gerade Runden grün, ungerade rot.

from gturtle import *

makeTurtle()
hideTurtle()

s = 10
repeat 200:
    if s % 2 == 0:
        setPenColor("green")
    else:
        setPenColor("red")
    forward(s)
    right(90)
    s = s + 1

Mit elif fragst du mehrere Fälle nacheinander ab. Geprüft wird von oben nach unten; der erste zutreffende Block gewinnt:

from gturtle import *

makeTurtle()
hideTurtle()

s = 10
repeat 150:
    if s < 60:
        setPenColor("red")
    elif s < 120:
        setPenColor("orange")
    else:
        setPenColor("green")
    forward(s)
    right(91)
    s = s + 1

Zufall: Punkte streuen

randint(a, b) aus dem Modul random liefert eine ganze Zufallszahl zwischen a und b. Setzt du damit viele Punkte und entscheidest per if, welche du überhaupt zeichnest, entstehen aus Zufall gezielt Formen und Muster.

from gturtle import *
from random import randint

makeTurtle()
hideTurtle()
setPenColor("red")

repeat 3000:
    x = randint(-150, 150)
    y = randint(-150, 150)
    if y > 0:                 # nur die obere Haelfte faerben
        setPos(x, y)
        dot(3)

Selbsthilfe

Wenn's klemmt

IndentationError

Die Einrückung stimmt nicht. Alles, was zu einer Schleife oder Funktion gehört, muss um gleich viele Leerzeichen eingerückt sein – am besten immer vier.

NameError: forward

Die erste Zeile from gturtle import * fehlt, oder du hast einen Befehl falsch geschrieben. Groß- und Kleinschreibung zählt: hideTurtle(), nicht hideturtle().

SyntaxError am Zeilenende

Der Doppelpunkt hinter repeat 4, if … oder der def-Zeile fehlt. Oder eine Klammer ist nicht geschlossen.

Nichts passiert

makeTurtle() vergessen – oder du hast eine Funktion nur definiert und nie aufgerufen. Der Aufruf steht ganz unten und darf nicht eingerückt sein.

Es zeichnet ewig

hideTurtle() direkt nach makeTurtle() einfügen. Ohne sichtbare Turtle ist die Zeichnung um ein Vielfaches schneller.

Die Figur läuft aus dem Bild

Startwerte verkleinern oder die Turtle vorher mit back(150) bzw. setPos(x, y) versetzen.
